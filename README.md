Участвовал в разработке мобильного и веб-интерфейса визуализации и анализа данных коммуникационных цепочек в сфере **IoT** для **OpenMetering** (Швеция).

Вместе с командой [**Staq Digital**](https://staq.ru/) создавал интерфейс мобильного и веб-решения для сотрудников служб обслуживания и ремонта. Платформа [STAQ](https://staq.ru/) автоматизирует операционные процессы предприятия: от управления заявками и обслуживания оборудования до мониторинга датчиков IoT и настройки бизнес-логики в визуальном редакторе. Проектировал интерфейсы для модулей мониторинга, приёма заявок, контроля оборудования и выездного сервиса — включая мобильное приложение для инженеров.
